# Earworm

Local-first web app: sing or hum into the page, shape the sound. Design: see docs/TDD.md.

Milestone M0 (two throwaway prototypes, Live follow and Influence match) is in this repo. To run it:

```sh
pnpm install
pnpm dev
```

See docs/M0.md for what each prototype tests, how to judge it, and what was measured.
