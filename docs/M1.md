# M1: engine core (work in progress)

Paused on 17 Nov 2026 at the owner's request. This page says what is built, what was measured so far, and what is left. The full guide (how to run, how to judge the gate) gets written when M1 is finished.

M1 per the [TDD](TDD.md) build order: voices, the drum model, space; the sequencer, rings and the offline host. Gate: 8 layers with no dropouts. It also has to measure the partial budget and the offline render speed on the reference laptop (2020 M1 MacBook Air, Chrome).

## Done (committed on `fm/earworm-m1`)

| Piece | Where | Notes |
| --- | --- | --- |
| Parameter table | `crates/params/params.toml` | All 64 scalars and the two 16-band shapes from the TDD, eight macros (bright, body, wobble, grit, space, punch, air, length; weights are provisional) |
| Generator | `tools/paramgen/paramgen.ts`, `pnpm gen:params` | Writes the Rust table, `web/src/gen/params.ts`, the JSON Schema for the LLM target and the parameter dictionary. A Vitest test fails if the generated files are stale |
| Mapping and resolution steps 2 and 3 | `crates/params/src/lib.rs` | Normalized to real units, Influence blend, macros, macro projection for the sliders |
| Engine wire formats | `crates/klont/src/protocol.rs` | Control messages, layer blob, meter block, buffer table, `ew_load` kinds |
| Voice | `crates/klont/src/voice.rs`, `crates/dsp/src/fx.rs` | 64-partial bank (SIMD in groups of four, checked in the wasm output), drum ring, pitch envelope, clicks, clang, fold, comb, filter, LFOs, chaos |
| Layer effects | `crates/dsp/src/layer_fx.rs` | Crush, tape, stereo delay with pitch shift, 8-line FDN reverb with freeze |
| Sequencer | `crates/klont/src/seq.rs`, `crates/klont/src/curve.rs` | Track tables, transport (tempo ramps, repeats, jumps, free time, uneven loops, sample-accurate events), curve tables read through warp maps. TypeScript encoder `web/src/m1/track.ts` with a shared binary fixture |
| Layers and engine | `crates/klont/src/layer.rs`, `crates/klont/src/engine.rs` | 8 layers x 8 voices, voice stealing, partial budget shared by loudness, automatic budget from host CPU load, gesture and hit-shape offsets, meters, the C ABI (`ew_init`, `ew_buffers`, `ew_process`, `ew_render`, `ew_load`, `ew_seek`, `ew_free`) |
| Native benchmark | `crates/klont/src/bin/bench.rs` | `cargo run --release -p klont --bin bench` |
| Tests | each module, plus `crates/klont/tests/` | `cargo test --workspace` passes. The engine tests include a counting allocator that fails if eight layers allocate while rendering |

From M0: the DSP crate is reused and extended. The M0 one-layer engine (`crates/engine`) stays as it is so the M0 pages keep working; the new engine is a separate crate, `crates/klont`. The M0 rings (`web/src/host/rings.ts`) are meant to be reused by the M1 worklet host.

Rust is not installed system-wide on the build machine. For this work a toolchain was installed under `~/firstmate/data/earworm-m1/toolchain`; `. ~/firstmate/data/earworm-m1/env.sh` puts it on the PATH.

## First measurement

Native, Apple M4 MacBook Air, worst case (8 layers x 8 held voices, vibrato on every voice, delay and reverb on every layer), 3 s per run:

| Budget | Active partials | x real time | Core load |
| --- | --- | --- | --- |
| 4096 | 2850 | 11.4 | 8.8% |
| 2048 | 2027 | 12.5 | 8.0% |
| 1024 | 1012 | 15.6 | 6.4% |
| 512 | 448 | 17.8 | 5.6% |

The worst case only reaches 2850 active partials, not 4096, because some partials fall below the -72 dB cut. The wasm numbers in Chrome, and the numbers on the reference laptop, are not measured yet.
