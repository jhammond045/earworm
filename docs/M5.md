# M5: The app, the click, and the project file

M5 is the first single app. Earworm before this was a set of milestone pages (live, Influence, m1, m2, m3, the M4 blind test). Those pages stay, and they are listed under **Tests**. The index page is now the app: one transport, one undo history, and one path from capture to the pattern, Influence, states and the morph lane.

The [PRD](https://claude.ai/artifact/3ZXQPGZdEtMPEqWRHxcQvi) could not be fetched from this session, so later milestones were checked against the TDD and against `docs/M3.md` and `docs/M4.md` only.

The TDD's Interface section names Svelte and a WebGL timeline. The repository is Vite and plain TypeScript, and the M3 page is already built that way. The app follows that, so the milestone pages and this shell share one document model. The pattern is a grid of the track (sections, layers, notes, hits, morph markers), not a copy of a tracker program's note columns.

## Run it

```sh
pnpm install
pnpm dev
```

Open the URL Vite prints. The dev server uses port 5173 and moves to the next free port if that one is taken. A server already on 5174 belongs to another checkout; leave it running and use the URL this checkout prints.

The index page is the app:

- **Start** opens the audio. **Start with mic** also asks for the microphone. Nothing turns the mic on until one of those, or **Enable mic** after a start without it.
- **Play** and **Stop** are the only transport. **Space** plays and stops when the mic is off, and holds a capture when the mic is on. **Escape** stops.
- **Metro** clicks on the beat, louder on the downbeat. **Lvl** is how loud. **Tick** is a plain click; **Kit** uses a slot of a beat layer. The click is mixed into the speakers only. A take recorded from the mic does not contain it, and an offline render does not either.
- Hold **Capture** on a stopped grid section and you hear one bar of count-in, then the section starts and the take is placed on the selected layer. Letting go during the count-in cancels it. A take under half a second is ignored.
- The **pattern** is the section: one column per layer, one row per 16th note (four rows a second in free time). Double-click or Enter adds a note or a hit. Arrows move the cursor. Shift with up and down changes a note's pitch. Delete removes the selected events. Keys 1–4 set a hit's kit slot. The row that is playing is highlighted. The small bars above the pattern are how many voices each layer has sounding.
- **Layers** add a melody, a beat or a texture, and a new section. The stepper in the top strip moves between sections. BPM edits the grid section on screen.
- **Sound** picks the preset, level and mute for the selected layer, the state being edited, and Influence: a file or hold **Listen**, amount, the five aspects, **Use the sound itself**, **Commit** and **Clear**. **Add marker at row** puts a morph marker on the selected layer at the cursor row.
- **File** is new, open, save, save as, rename, delete, export zip, import zip, and clean up. The project is journaled as you edit; Save writes that journal now. Export is one zip of the document and the audio it names. Import reads that zip, including a project from an older schema. Clean up drops takes and sources that nothing in the song or the undo stack still uses. Undo of that cleanup puts the take back in the document; the audio file itself is gone.
- **Learn** opens the walkthroughs and the three demos (Melody, Beat, States). A walkthrough highlights a control and waits for the action. Skip moves on without it. The lessons are data in `web/src/app/tutorials.ts`.

**Tests** links the existing pages: live, live test, live session, Influence, Influence test, delay, m1, the benchmark, m2, the M3/M4 track page, and the M4 blind match. Their gate checks are unchanged.

Undo and redo are one stack for the whole app (Cmd/Ctrl+Z, Cmd/Ctrl+Shift+Z, Ctrl+Y). On a narrow window the Layers, Pattern and Sound panels switch with the tab row; from 960px wide they sit side by side. Controls are buttons, inputs and a grid, so they take the keyboard. Motion is reduced when the system asks for it.

Tests:

```sh
pnpm test
```

The metronome tests on their own:

```sh
cargo test -p klont --test metro --test engine --lib
```

## What is built

| Piece | Where |
| --- | --- |
| Sample-accurate click and one-bar count-in. The click is scheduled from the transport clock (the same edge the sequencer uses), not a browser timer. Count-in positions are a closed form, so the block size does not move them. Kit voice triggers a beat-layer slot; anything else is the tick. Live output only: `ew_render` stays silent, and the mic buffer is the input without the click | `crates/klont/src/metro.rs`, `engine.rs`, `seq.rs`, `protocol.rs`; `crates/klont/tests/metro.rs` |
| Meter slots for the click, the beat in the bar, the count-in and its sequence | `M_METRO` 260 through `M_COUNT_SEQ` 263, mirrored in `web/src/m1/protocol.ts` |
| Browser build of that engine | `web/public/wasm/klont.wasm` |
| Project schema 3: a `metro` object (on, level, tick or kit, layer, slot, bar). Opening an older project, including one still in the undo journal, adds it | `web/src/project/types.ts`, `migrate.ts` |
| `setMetro` and `forgetTakes` | `web/src/project/commands.ts` |
| Which takes and blobs the song and the undo stack still need | `web/src/project/cleanup.ts` |
| Zip export and import. Export writes stored entries (`project.json` plus `blobs/<ref>.f32`). Import also reads deflate. Unsafe paths are rejected. A document is migrated on the way in | `web/src/project/archive.ts` |
| Pattern geometry: rows, the play row, the cell label | `web/src/app/pattern.ts` |
| Three demo projects, built with the same commands as a saved song | `web/src/app/demos.ts` |
| Walkthrough lessons as data, and the runner that advances them | `web/src/app/tutorials.ts`, `tutorial.ts` |
| Hold-to-capture with the engine count-in | `web/src/app/capture.ts` |
| The app shell | `web/index.html`, `web/src/app/main.ts`, `web/src/app/style.css` |

### How the click lines up

At 120 bpm and 48 kHz a beat is 24000 samples. With the metronome on, a click is mixed on sample 0 and again on 24000, and the downbeat is louder. A count-in of four plays those four clicks and the transport starts at sample 96000, which is the downbeat of the section, not a fifth click. The same positions come out of a 64-sample block and a 512-sample block. While the transport is stopped, loading a track arms the downbeat under the playhead so the first beat is not swallowed. While it is playing, an edit does not re-click the beat already sounding.

### How a project is kept

Named projects stay in IndexedDB (the journal and the snapshot) with their audio in OPFS, which M3 already did. Schema 3 is one more migration step on that path. The zip is the file you can take elsewhere. Cleanup walks sections, layers and the undo and redo stacks for take ids and `grain-` / `audio-` / `frames-` refs. It does not treat the takes map itself as a use, or every take would look needed.

## Not in this app, on purpose

- **Hosting and deploy.**
- **The LLM sound endpoint.**
- **Refine (CMA-ES).** The Influence match is the one M4 shipped.
- **A WebGL timeline in the shell.** Melody and hits are the pattern cells; the morph lane is the marker row under the grid. The canvas timeline, the ribbon drawing, macros and "use my sound for a kit slot" stay on `m3.html`.
- **Per-layer waveforms.** The engine's layer peak only rises, so the strip shows how many voices are sounding.
- **The echo canceller.** Capture and Listen still assume headphones. Nothing mutes the speakers.

## Known limits

- Count-in seeks to the start of the current section and then uses that section's bpm. The engine does not seek on its own when the count-in ends.
- The click during playback follows `metro.bar` (default 4), not the length of the section.
- A kit click needs a beat layer that is not muted. Otherwise you hear the tick.
- Clean up deletes blob bytes. Undo restores the document entry and cannot bring the audio back.
- Opening a demo copies it into a new project. Saving does not replace the built-in demo.
- The walkthrough can be skipped. A step that needs the mic waits, and Skip is there when the mic is not.
